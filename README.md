## 🌸 My Journey & Ambitions 🌸

</div>

I'm **Anjali**, a passionate junior network engineer on a mission to become a skilled **Network Engineer and Network Administrator**. I fell in love with networking the moment I first traced a packet through the OSI model — understanding *how* data travels, *why* routes are chosen, and *what* keeps networks secure is endlessly fascinating to me.

My dream is to design, manage, and secure enterprise-grade networks — from configuring core routers and switches to implementing robust security policies that protect real-world infrastructure. I believe every network has a story, and I want to be the one who writes it.

> 💬 *"A network engineer's job is never done — there's always a new protocol to learn, a new topology to design, and a new problem to solve."*
